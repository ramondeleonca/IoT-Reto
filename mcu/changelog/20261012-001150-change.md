# Change: Refresh Active Signal for New Objects

- **Date and time:** 2026-10-12 00:11:50
- **Change summary:** Restart the active signal's reset countdown when another object passes both sensors.
- **Files modified:**
  - `src/impl/main.hpp`
  - `changelog/changelog.md`
- **Description of the changes:**
  - Record sensor rising edges even while `active` is true.
  - On each newly paired trigger within `triggerWindow`, update `activeSince` to start another full reset interval.
  - Clear paired timestamps after detection so the same pair cannot be counted repeatedly.
- **JUSTIFICATION FOR THE CHANGES:**
  Previously, active state prevented new sensor edges from being recorded, so the signal could not refresh while its reset timer was running. Allowing fresh pairs through keeps it active until 2000 ms after the most recently detected object.
- **The prompt that caused it:**
  "instead of blocking itself because of the reset time, it should reset itself if a new object passing by was detected (and then wait another 2000ms before deactivating)"
