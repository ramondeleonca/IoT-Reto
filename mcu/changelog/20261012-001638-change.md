# Change: Add Velocity Threshold and Active LED

- **Date and time:** 2026-10-12 00:16:38
- **Change summary:** Activate the signal only above the configured velocity threshold, show its state on the built-in LED, and log when it deactivates.
- **Files modified:**
  - `src/impl/main.hpp`
  - `changelog/changelog.md`
- **Description of the changes:**
  - Require calculated velocity to be greater than `thresholdVelocityMMperS` before activating or refreshing the signal.
  - Turn the built-in LED on when the signal activates and off when its reset timer expires.
  - Print a short message when the signal deactivates.
- **JUSTIFICATION FOR THE CHANGES:**
  The signal and LED should reflect only objects moving faster than the configured threshold; the deactivation message makes the end of the active interval visible over Serial.
