# Change: Simplify Sensor Trigger Logic

- **Date and time:** 2026-10-12 00:05:50
- **Change summary:** Preserve the original loop structure while simplifying sensor trigger and active-signal timing.
- **Files modified:**
  - `src/impl/main.hpp`
  - `changelog/changelog.md`
- **Description of the changes:**
  - Timestamp each sensor's rising detection edge directly in the existing loop.
  - Replace the multi-branch window calculation with one elapsed-time check.
  - Keep the active latch and its reset-time behavior.
  - Retain expiration of unmatched sensor triggers after the configured window.
- **JUSTIFICATION FOR THE CHANGES:**
  The previous implementation added separate current-time variables and several branches that were unnecessary for the original polling-loop structure. The shorter pairing check keeps the same behavior while making the code easier to follow.
