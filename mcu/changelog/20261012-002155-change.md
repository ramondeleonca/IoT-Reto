# Change: Switch Sensors to Continuous Ranging

- **Date and time:** 2026-10-12 00:21:55
- **Change summary:** Run both VL53L0X sensors in continuous ranging mode and poll for completed measurements without blocking.
- **Files modified:**
  - `src/impl/main.hpp`
  - `changelog/changelog.md`
- **Description of the changes:**
  - Set high-speed measurement timing budgets to 20 ms and start 20 ms continuous ranging for both sensors.
  - Replace blocking single-shot reads with readiness checks and retrieval of completed range results.
  - Preserve each sensor's latest distance and process trigger edges only when new readings arrive.
  - Print distances when either sensor has a new measurement instead of flooding Serial on every loop iteration.
- **JUSTIFICATION FOR THE CHANGES:**
  Waiting for sequential single-shot measurements delayed the loop. Continuous ranging lets the sensors measure in the background while the loop checks readiness, with a 20 ms budget/period for faster updates than the previously discussed 40 ms cadence.
- **The prompt that caused it:**
  "let's do that, but 40ms still feels slow"
