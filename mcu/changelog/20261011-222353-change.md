# Change: Measure Velocity Between Time-of-Flight Sensors

- **Date and time:** 2026-10-11 22:23:53
- **Change summary:** Log both measured distances continuously and log object velocity after an object crosses between the sensors.
- **Files modified:**
  - `src/impl/tof.hpp`
  - `src/impl/tof_servo.hpp`
  - `changelog/changelog.md`
- **Description of the changes:**
  - Treat a valid distance of 30 mm or less as object detection.
  - Record the first sensor's detection time and calculate velocity when the other sensor detects the object.
  - Report velocity in mm/s and handle either sensor crossing first.
  - Keep the existing continuous distance output.
  - Set sensor 2 to its declared, unique I2C address.
- **JUSTIFICATION FOR THE CHANGES:**
  Velocity requires both a known sensor separation and elapsed time between detections. Edge detection prevents repeatedly counting an object while it remains in the sensor's detection range. The two sensors also need distinct I2C addresses to be read independently.

  "modify as little as possible in the code to detect object velocity based on the time it takes to cross from one sensor to the other and the distance set as sensorDistanceMM, always log the distance, but when an object is detected log it to serial"
